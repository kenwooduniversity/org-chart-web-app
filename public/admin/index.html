People & access

Everyone with a verified @kenwoodusa.org Google account can sign in. What they can do in each tool is set here: Viewer can look, Editor can change data, Admin can also import and restore. "Default" uses the tool's default below. Changes apply immediately and are enforced by the database's security rules.

You can add people before they've ever signed in.

Tools

The default role applies to every Kenwood account that doesn't have its own setting above. "Coming soon" tools appear on the home page but can't be opened.
